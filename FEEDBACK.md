# ShieldScore — Community & User Feedback

We welcome feedback, suggestions, and feature requests from DeFi lenders, risk officers, and privacy researchers.

### How to Provide Feedback
- **GitHub Issues:** Open an issue on this repository to report bugs or request new circuit predicates.
- **Midnight Discord:** Join the community at [Midnight Discord](https://discord.com/invite/midnightntwrk) in the `#dev-discussion` channel.
- **Protocol Improvement Proposals:** Propose new Compact financial circuits via pull requests.
